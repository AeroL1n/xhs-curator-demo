# 灵感主理人 AI Curator · 交互 Demo

小红书「收藏」Tab 的功能创意：在收藏列表上方出现一枚"灵感胶囊"，点开后把沉在收藏夹里的同主题笔记整理成一块可勾选、可回溯来源的灵感看板。

**可交互链接：<https://aerol1n.github.io/xhs-curator-demo/>**

建议用电脑浏览器打开。页面是单文件 HTML，左侧是说明面板，右侧是可点击的手机框。

## 怎么玩

1. 点左侧「自己试试」，进入收藏 Tab，约 0.6 秒后灵感胶囊淡入。
2. 点胶囊（按住会缩放，松手打开），底部弹出灵感看板，装备清单、营地路线、避坑提醒依次浮现。
3. 拖动看板把手可在两档高度间吸附，下拉关闭。勾选装备会更新"已备"数量。
4. 点「N 篇提到」或底部来源封面，会提示将跳转原笔记。
5. 点「存为清单」，看板收起，胶囊变为"已整理"，来源笔记挂上"已回顾"角标。
6. 长按胶囊，选「不再推荐」，4 秒内可撤销。
7. 点「看核心链路演示」，自动播放完整流程并配旁白，可随时停止。

## 说明

- 示例内容是虚构的「周末露营」场景，图片用渐变和线稿占位，不含真人照片与平台素材。
- 无外部依赖，所有状态保存在页面内存里，刷新后回到初始状态。
- 本地查看：下载 `index.html` 后双击打开即可。
