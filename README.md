# 灵感主理人 AI Curator · 交互 Demo

小红书体验设计「AI 与社区」方向的提案：把「收藏」Tab 从存放笔记的仓库，升级为由 AI 主理的灵感空间。收藏列表上方常驻一枚「灵感胶囊」，也可以主动说出整理需求，AI 把沉在收藏夹里的同主题笔记整理成一块可勾选、可回溯来源、可继续补充的灵感看板，一键存为专辑。

**可交互链接：<https://aerol1n.github.io/xhs-curator-demo/>**

建议用电脑浏览器打开。页面是单文件 HTML 加本地图片素材，左侧是说明面板与演示入口，右侧是可点击的手机框。

## 它解决什么问题

收藏 ≠ 学会使用：用户收藏了大量露营、穿搭、探店笔记，真要用的时候还是要逐篇翻。提案的核心是三条链路：

1. **被动推荐**：收藏行为触发「灵感胶囊」，点开直接预览 AI 整理好的看板，不必先选笔记。
2. **主动整理**：一句话说清需求（如"整理周末露营的装备清单"），看板按需求重组；无结果时才兜底自行选笔记。
3. **持续使用**：看板存为专辑后保留勾选进度，AI 补充基于已有收藏查漏，每一条内容都能回溯到原笔记。

## 怎么玩

1. 点左侧「推荐整理」，进入收藏 Tab，灵感胶囊淡入后点开，看板自动生成。
2. 勾选装备更新"已备"进度；点「N 篇提到」查看条目的参考来源，可回到原笔记。
3. 切到「主动整理」，输入需求或直接提交，观察看板按需求变化。
4. 点「存为专辑」创建专辑，详情页保留看板入口与进度。
5. 在专辑里点「AI 补充」，AI 先筛相关收藏，确认后更新看板。
6. 条目可删除并撤销；来源笔记始终保留在原收藏里。
7. 「删除与撤销」场景单独演示 关闭推荐 / 删除条目 / 新建专辑 的撤销链路。
